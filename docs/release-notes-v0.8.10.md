# v0.8.10 发布说明

**发布时间**：2026-11-14 · **版本** `0.8.10+2010` · 三个 ABI 包（arm64-v8a / armeabi-v7a / x86_64）

这一版让**一台手机可以保存多个账号**：切号不用重新收验证码，每个账号各自一套账本，
切号时会先把当前账号备份到云端、再把目标账号的数据装回本机。

---

## 一、多个账号，各记各的账

- 「设置 → 数据 → 云同步」退出后，页面会列出**这台手机用过的账号**（邮箱 + 上次使用时间）；
  点一下就能切回去，**不用再收验证码**；
- 每个账号**各自一套账本**：切到哪个账号，就只看到那个账号的账本、流水、统计；
- 新账号第一次登录会**自动建一个默认账本**（预置账户与分类照旧）；
- 你原来的本机账本会在首次登录时**归到这个账号名下**，数据一条不丢。

## 二、切号会自动搬运数据

点账号切换时会依次：

1. **把当前账号的数据备份到云端**（全量，与「备份」按钮同一套格式）；
2. 切换登录态；
3. **把目标账号的云端备份装回本机**，再补齐这之后的改动。

进度会在一个**不能取消**的弹层里显示 —— 因为中途取消会留下「备份完了、只拉了一半」的怪状态。
**任何一步失败都会自动退回原账号**，不会把你挂在半路上。

## 三、退出、移除与隐藏

- **退出登录**：只回到未登录视图，**token 仍保留** —— 下次点一下这个账号就回来；
- **移除账号**：清掉本机的登录状态；**云端数据不动，本地属于它的账本也保留但隐藏**，
  以后用同一邮箱再登录，账本原样回来；
- 从未登录过的用户（只用本机记账）**一切照旧**，不会看到登录墙。

## 四、顺手修掉的升级问题

从 v0.8.9 升级上来时，旧账本可能没被认领到账号名下（表现为账本列表变空），
甚至可能凭空多出一本空账本 —— 这两个问题都已在正式包里修掉。

## 五、装哪个包

| 你的手机 | 下哪个 |
|---|---|
| 绝大多数近几年的 Android（arm64） | **arm64-v8a** |
| 很老的 32 位机器 | armeabi-v7a |
| 模拟器 / x86 平板 | x86_64 |

三个包**同一把签名**，可直接覆盖安装 v0.8.9，账本数据保留。
覆盖安装后「我的」页角标应显示 **v0.8.10**。

## 六、已知限制

- 同一时刻只有**一个当前账号**（不做多账号同时在线）；
- 账本不能共享给别人；
- 切号需要网络（备份与拉取），任一环节失败会回滚；
- 冲突仍按「后改的赢」自动裁决，本机版本可在「云同步 → 冲突详情」里恢复。
