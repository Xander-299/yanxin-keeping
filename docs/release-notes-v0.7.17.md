# 颜芯记账 v0.7.17

本地优先的个人记账 App（Flutter / Android）。数据全部存在手机本地，**无账号、无服务器、无网络请求**。

## 本次更新：深色模式

「我的 → 设置 → 外观」新增三选一：**浅色 / 深色 / 跟随系统**（默认跟随系统）。

- 选择立即生效，不用重启；下次打开还是这一项
- 「跟随系统」下，手机切到深色 / 浅色，App 立刻跟着变
- 只影响外观，不影响账本数据

深色不是「把颜色反过来」，而是一整套「卡通夜灯」：暖黑画布 + 暖白描边 + 纯黑硬阴影，
品牌琥珀不变，hero 主卡仍是琥珀（夜里唯一的一盏灯）。
所有前景 / 背景组合都按 WCAG 对比度量过并修到位，文字与描边在深色下都可读。

## 安装

1. 把 APK 传到手机（数据线 / 微信文件传输助手 / 网盘均可）。
2. 用文件管理器点击安装。系统会提示「未知来源应用」—— 按提示允许**当前这个应用**（如文件管理器）安装即可。
3. 安装完成后桌面出现橙色「记一笔」图标。

> ⚠️ **不要从应用商店下载**（本项目未上架）。
> ⚠️ 首次启动会弹 7 页新手引导，可随时在「我的 → 新手引导」重看。

## 开启自动记账（可选）

App 的手动记账功能**开箱即用**。若要让「微信 / 支付宝支付通知自动入账」，需要额外两步：

1. **授予通知使用权**：手机「设置 → 应用 → 颜芯记账 → 通知使用权」→ 打开。
   - 不同品牌路径略有差异：小米 / Redmi 在「设置 → 通知与控制中心 → 通知使用权」；
2. **允许发通知**（Android 13+ 需运行时授权），然后去付一笔钱并**打开一次本 App** 验证。

> ⚠️ 国产 ROM 必读：强行停止或覆盖安装后，系统会**自动解绑**通知监听服务（设置里仍显示「已开启」）。
> 遇到不生效，把通知使用权**关掉再打开一次**即可恢复。
> ⚠️ 支付通知在国产 ROM 上只活约 26 秒，App 内已做「主动补抓 + 撤回捕获」两层兜底；
> 产品侧仍明确建议「支付后打开本 App 一次」最稳。
