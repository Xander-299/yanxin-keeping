## 3. 发现的问题

### 1（已修）「我的」页版本号停在 `v0.7.16`

- **现象**：走查截图里「这一版覆盖到哪」右上角仍写 `v0.7.16`；覆盖内容也没提外观主题。
- **原因**：`profile_page.dart` 的版本号是**硬编码字符串**，发版时要手动改。
- **处置**：改 `v0.7.17` + 覆盖清单追加「浅色 / 深色 / 跟随系统」→ 重建复验。

### 2（记录，不改）左滑「删除」白字在深色红底上对比度约 2.8:1

- 深色主题把 `red` 提亮到 `#FF6B6B`（暗底上更跳），白字压在它上面时对比 ≈ **2.79:1**
  （浅色 `#FF5D5D` 为 ≈3.01:1），略低于 WCAG 3:1 的大字门槛。
- **不改的理由**：`red` 同时用于「支出金额」（暗底上必须亮），不能为按钮单独压暗；
  改文字色会与浅色主题的口径不一致。属既有设计妥协，记在此处待设计侧决定。

### 3（记录）强制深色 + 系统浅色时的白色启动图

SPEC §3.4 已登记：Android 启动主题由系统深浅决定，Dart 侧改不了；只能靠 `main()` 预热把空窗压短。
