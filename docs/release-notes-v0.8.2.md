# 小耄记账 v0.8.2

本地优先的个人记账 App（Flutter / Android）。数据全部存在手机本地，**无账号、无服务器、无网络请求**。

## 本次更新：换名字、换图标，外加一整个月的功能

### 1. App 改名「小耄记账」，图标换成橙底小猫

- 桌面名字、应用内的标题、通知文案、导出的文件名前缀，全部改成 **小耄记账**
  （导出文件现在是 `小耄记账_账本_日期.csv`）
- 图标换成橙底小猫（`#EB7118`），桌面图标、通知小图标、网页版 favicon 一起换
- **包名不变**（`com.teacodeman.yanxin`）、**签名不变** → 老版本可以直接覆盖安装，账本一条都不丢

> 上一版（v0.8.1）虽然已经改名，但那个安装包里仍是旧名字和旧图标 —— **这一版才是真的换上了**。

### 2. 分类可以分两级

- 支出侧预置 **10 个一级分类 + 33 条二级分类**（餐饮 → 早餐 / 午餐 / 晚餐 / 饮料 / 零食 …）
- 分类管理页改成折叠式：点一级展开二级，块状排列，右上角「⋯」出操作菜单
- 新建 / 编辑分类弹层重做：名称常驻、图标另开弹层挑、右下角常驻浮动按钮
- 问账本时「这个月餐饮花了多少」会**按父级汇总**（二级自动计入一级）

### 3. 主题色五选一

「我的 → 设置 → 主题色」：**森绿**（默认）/ **琥珀** / **黛蓝** / **藕粉** / **墨紫**。
换的是整套品牌配色（hero 卡、按钮、选中态、图表首瓣），页面版式不变；浅色 / 深色两套都跟着走。

### 4. 日历页更顺

- **分段加载**：打开就先看到月历网格和汇总条，某天的账单随后补上，不再整页转圈
- **不能翻到未来月**（与首页口径一致，未来的日子灰掉）
- **翻月不改选中日**：翻到别的月份只是看，下面账单仍是你选的那天，直到你点别的日子

### 5. 一句话问账本 / 发截图记账

- 首页「记一笔 / 问一句」入口：一条聊天流里既能打字问账本（本月花了多少、某分类多少、
  预算还剩、为什么比上月多、大额支出 …），也能直接发一张微信 / 支付宝账单截图
- 截图走**手机本地 OCR**（ML Kit 中文离线包），识别→规则解析→待确认卡，**点确认才入账**
- 全程离线，正式包**连 `INTERNET` 权限都没有**

## 安装

1. 把 APK 传到手机（数据线 / 微信文件传输助手 / 网盘均可）。
2. 用文件管理器点击安装。系统会提示「未知来源应用」—— 按提示允许**当前这个应用**（如文件管理器）安装即可。
3. 安装完成后桌面出现橙底小猫图标、名字是「小耄记账」。

> ⚠️ **不要从应用商店下载**（本项目未上架）。
> ⚠️ 老用户覆盖安装后，桌面图标与名字可能需要几秒刷新；个别 ROM 要重启桌面才变。

## 开启自动记账（可选）

App 的手动记账功能**开箱即用**。若要让「微信 / 支付宝支付通知自动入账」，需要额外两步：

1. **授予通知使用权**：手机「设置 → 应用 → 小耄记账 → 通知使用权」→ 打开。
   - 不同品牌路径略有差异：小米 / Redmi 在「设置 → 通知与控制中心 → 通知使用权」；
2. **允许发通知**（Android 13+ 需运行时授权），然后去付一笔钱并**打开一次本 App** 验证。

> ⚠️ 国产 ROM 必读：强行停止或覆盖安装后，系统会**自动解绑**通知监听服务（设置里仍显示「已开启」）。
> 遇到不生效，把通知使用权**关掉再打开一次**即可恢复（本次覆盖安装也会触发，记得重开）。
