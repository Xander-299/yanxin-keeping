# 颜芯记账 v0.7.16

本地优先的个人记账 App（Flutter / Android）。数据全部存在手机本地，**无账号、无服务器、无网络请求**。

| `app-arm64-v8a-release.apk` | 只想给 **arm64 现代机**（体积小一半） | ~25 MB |

## 安装

1. 把 APK 传到手机（数据线 / 微信文件传输助手 / 网盘均可）。
2. 用文件管理器点击安装。系统会提示「未知来源应用」——按提示允许**当前这个应用**（如文件管理器）安装即可。
3. 安装完成后桌面出现黄色「记账」图标。

> ⚠️ **不要从应用商店下载**（本项目未上架）。
> ⚠️ 首次启动会弹 7 页新手引导，可随时在「我的 → 新手引导」重看。

## 开启自动记账（可选）

App 的手动记账功能**开箱即用**。若要让它**自动从微信/支付宝通知里记账**，需要额外两步：

1. **授予通知使用权**：手机「设置 → 应用 → 颜芯记账 → 通知使用权」→ 打开。
   - 不同品牌路径略有差异：小米/Redmi 在「设置 → 通知与控制中心 → 通知使用权」；
     华为/荣耀在「设置 → 应用和功能 → 应用管理 → 颜芯记账 → 通知使用权」。
2. **允许通知本身**：系统设置里「颜芯记账 → 通知」打开，允许发通知。

之后去微信/支付宝付一笔钱，回到 App 打开一次，流水就会自动出现。

> ⚠️ **国产 ROM 特别注意**（小米/红米实测）：
> - 强行停止 App 或覆盖安装后，系统会**自动解绑**通知监听服务（但设置里仍显示「已开启」）。
>   → 遇到「自动记账不生效」时，**把通知使用权关掉再打开一次**即可恢复。
> - 支付类通知在部分 ROM 上**只存活约 26 秒**（点进「支付成功」页就被撤回）。
>   → **付完款后尽快打开一次本 App**，App 会主动回捞通知栏里还存在的记录。

> App 不会读取通知内容用于其它用途，也不会上传任何数据 ——
> 通知文案在**手机本地**解析成金额后就丢弃，数据库只有金额、分类、备注和时间。

## 数据与隐私

- **全部本地**：SQLite（drift）单文件，存在 App 私有目录，卸载即删除。
- **无网络权限**：release 包不申请 `INTERNET`（debug 包有，那是 Flutter 热重载用的）。
- **无账号、无埋点、无广告**。
- 想备份：「我的 → 数据导出」可导出流水 CSV 与完整 JSON 备份（走系统文件选择器，不申请存储权限）。
