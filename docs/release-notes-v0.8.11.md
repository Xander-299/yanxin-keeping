# v0.8.11 发布说明

**发布时间**：2026-11-14 · **版本** `0.8.11+2011` · 三个 ABI 包（arm64-v8a / armeabi-v7a / x86_64）

这一版是 v0.8.10 多账号的**收尾修复**：把两轴代码评审查出来的真问题补上。
没有新功能，都是「本该如此」的行为。

---

## 一、修掉的问题

- **退出登录后账本区域没刷新**：以前点「退出登录」，界面上还挂着上一个账号的账本；
  现在会正确回到「未登录」状态。
- **账号邮箱大小写**：用 `Name@Example.com` 这种写法登录/切换，以前会认成另一个账号、
  账本像是丢了；现在统一按小写处理，和服务端一致。
- **未登录时的入口**：这台手机用过云同步、退出后账本列表是空的 —— 以前没有任何提示；
  现在抽屉里会写「这台手机用云同步记过账。选择一个账号，账本就会回来。」并给一个
  **「选择账号」按钮**，直接跳到账号列表。
- **不会再凭空多出一个空账本**：在没有当前账号的状态下，某些入口（如恢复备份）以前会
  悄悄建一本无归属的账本；现在会明确提示先选账号。
- **切号进度文案**：现在会写清「正在备份 `xxx@xx`…」「正在切换到 `yyy@yy`…」，
  不再只是「当前账号」。

## 二、内部一致性

- 切号 / 退出 / 移除账号后的刷新统一走同一个入口（不再各写一份，避免漏刷）。
- 冷启动不再触发多余的界面刷新。

## 三、装哪个包

| 你的手机 | 下哪个 |
|---|---|
| 绝大多数近几年的 Android（arm64） | **arm64-v8a** |
| 很老的 32 位机器 | armeabi-v7a |
| 模拟器 / x86 平板 | x86_64 |

三个包**同一把签名**，可直接覆盖安装 v0.8.10，账本数据保留。
覆盖安装后「我的」页角标应显示 **v0.8.11**。

## 四、已知限制（与上一版相同）

- 同一时刻只有一个当前账号；账本不能共享；
- 切号需要网络，失败会自动回滚到原账号；
- 冲突仍按「后改的赢」自动裁决，本机版本可在「云同步 → 冲突详情」里恢复；
- 自动同步只在 WiFi、只在 App 前台。
