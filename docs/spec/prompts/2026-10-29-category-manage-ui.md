# 任务书原文（2026-10-29 · 分类管理页交互升级）

> 用户原话存档（供 SPEC 引用；本文件只存档，不改写）。

请调整分类管理页面的交互与布局：

1. **一级分类：** 使用 Collapse（可展开/收起）交互。点击一级分类后，在当前分类项下方内联展开或收起对应的二级分类，不要将所有二级分类统一展示在页面其他位置。展开和收起应具有自然的过渡动画。

2. **二级分类：** 使用横向流式布局（`Wrap`），允许多个二级分类在同一行排列，并在可用宽度不足时自动换行。每个二级分类只占据自身所需的宽度，不要让每个分类独占一行。

3. **溢出菜单：** 将一级分类右侧的三点溢出菜单（Overflow Menu）改为 ActionSheet 风格的底部操作面板（Flutter 中优先考虑 `showModalBottomSheet`）。点击三点图标后，从屏幕底部弹出操作面板，展示该分类的相关操作，而不是使用传统的 PopupMenu。

4. **保持现有业务逻辑：** 复用已有的分类数据模型、编辑流程、停用逻辑及账单关联处理。不要为了实现 UI 效果而擅自修改数据库结构或业务规则。

5. **修改前先检查现有实现和相关 Spec，确认当前组件结构、分类层级及删除/停用规则；实现后运行相关测试，并汇报修改文件、测试结果及尚未解决的问题。**
